# Source code availability (GPLv3)

yanas net is distributed under the **GNU General Public License v3.0 or later**
(see `LICENSE` and `COPYRIGHT`).

When you receive a binary build (for example `netsim.exe`), the corresponding
source code is provided as the `yanas-net-<version>.tar.gz` archive distributed
alongside it, or from the project's public repository. That archive contains
everything needed to build the same program:

- `core/`, `device/`, `link/`, `engine/`, `topo/`, `app/`, `script/`, `win/`
- `third_party/lua/` (bundled Lua 5.4.6, MIT)
- `Makefile`, `Makefile.win`, `CMakeLists.txt`
- docs, tests, and licensing files

If you received a binary without access to the corresponding source, contact the
distributor to obtain it (GPLv3, section 6).
